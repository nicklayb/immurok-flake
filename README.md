# immurok-nix

Nix package and NixOS module for [immurok](https://github.com/immurok/app-linux-rs),
the Linux companion app for the immurok BLE fingerprint key: a system daemon
(BLE over BlueZ), a per-user session agent, a PAM module, a CLI/TUI and a GTK
settings app.

## Usage

```nix
{
  inputs = {
    nixpkgs.url = "github:NixOS/nixpkgs/nixos-unstable";
    immurok.url = "github:<owner>/immurok-nix";
    immurok.inputs.nixpkgs.follows = "nixpkgs";
  };

  outputs = { nixpkgs, immurok, ... }: {
    nixosConfigurations.my-host = nixpkgs.lib.nixosSystem {
      system = "x86_64-linux";
      modules = [
        immurok.nixosModules.default
        {
          hardware.bluetooth.enable = true;
          services.immurok = {
            enable = true;
            pam.services = [ "sudo" "polkit-1" ];
          };
        }
      ];
    };
  };
}
```

Then pair and enroll with `immurok-gui` (setup wizard) or `immurok-cli tui`.

## Differences from upstream packages

- PAM lines are generated by NixOS from `services.immurok.pam.services`.
  The app's *PAM* page and `immurok-cli pam install` cannot edit the
  read-only `/etc/pam.d` and are not supported; `immurok-pam-helper` is not shipped.
- The GUI autostart entry is controlled by `services.immurok.autostartGui`.
- Daemon flags go through `services.immurok.daemonArguments` (e.g. `[ "--debug" ]`).

## Outputs

`packages.<system>.{immurok,default}`, `overlays.default`,
`nixosModules.{immurok,default}`, `checks.<system>.{package,module-evaluation}`
for `x86_64-linux` and `aarch64-linux`.
